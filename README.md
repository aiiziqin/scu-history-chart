# 四川大学院系历史沿革全景图（1896—2026）

以 Excel 网格风格展示四川大学各学院、实体研究院所的百年源流：每列一个学院（按学部分组、竖排院名），每行一个年份，单元格颜色代表该学院当年所属的母体大学。

## 看图说明

- **列** = 学院（表头竖排院名，按理学/工学/医学/人文社科/实体研究院所分组）
- **行** = 年份（左侧逐年标注）
- **颜色** = 当年所属母体大学：
  - 🔵 蓝 — 四川大学
  - 🟣 紫 — 四川联合大学（1994—1998，原川大各系所统一显示）
  - 🟠 橙 — 成都工学院 / 成都科学技术大学
  - 🌸 粉 — 华西协合大学 / 四川医学院 / 华西医科大学
  - 🟢 绿 — 四川化学工业学院（1952—1955）
  - ⬜ 灰褐 — 其他来源（燕京大学、教会医院等）
- **半透明色块** = 筹建/中断期；**表头区浅色** = 早于 1896 年基线的源头期（如尊经书院 1875）
- **并 / 分 圆点**（色块分界处）= 红“并”为并入/合组，绿“分”为分出/调出，悬停看详情
- **右栏流向圆标**（入 / 出 / 内 / 组）= 跨院系·校际师资与系科流向：入=调入川大体系，出=调出至他校或新建院校，内=校内院系之间的调整（含校内分设），组=由多校/多系合组；悬停看该年该类逐条流向，点击进入《流向清单》页面（可用图上方复选框开关该图层）
- 悬停任意色块可查看当时名称与起止年份
- 页面**右上角顶栏**：显示本站/本页**浏览量**（不蒜子统计，离线或被拦截时自动隐藏）与**项目地址**（GitHub 仓库）

## 文件

- `index.html` — 全景图主页（点击学院名/色块可进入学院页；右栏为流向图层）
- `college.html` — 学院子页面（条状历史大图，点击时期条目进入详情页）
- `period.html` — 时期详情页（该时期的大事记、成就、代表人物）
- `flows.html` — 跨院系·校际师资与系科流向清单（按年份分组，可按 入/出/内/组 筛选与关键词搜索，支持 `?y=1952&k=出` 定位）
- `SOURCES-COMMUNITY.md` — 社群线索与查证台账（QQ 群具名线索 → 官方来源逐条对照，说明图中“据社群反馈”类表述的依据）
- `PEOPLE-LINKS.md` — 人物词条链接口径（官方页优先 → 百科兜底 → 暂不挂；含官方页对照表与待补名单）
- `tools/build-dist.js` — 导出脚本：`node tools/build-dist.js 1.0` 把 `data.js` 内联进页面，生成 `dist/`
- `tools/check.js` — 回归校验脚本：`node tools/check.js`（加 `--urls` 追加来源 URL 在线存活检查）
- `dist/` — 导出版（构建产物）：四个自包含页面 + `单文件版-四川大学院系沿革图-v1.0.html`（提交入库便于直接分发）
- `data.js` — 共享数据层（院系沿革 `ROWS` + 并/分事件 `EVMARKS` + 师资与系科流向 `FLOWS` + 时期详情 `DETAILS`，可在 `DETAILS` 中继续补充各时期资料）

## 数据说明

院系沿革与研究所信息整理自四川大学校史网及各学院官网公开资料，悬停提示中附关键年代与人物（如芶清泉 1984 年创建原子与分子物理研究所、卿希泰 1980 年创建宗教学研究所等）。如发现出入欢迎提 Issue。

- **时期详情覆盖**：212/212 个时期（100%），每条均含大事记与 GB/T 7714 格式出处；
- **列数** 45（含匹兹堡→奥克兰学院、灾后重建与管理学院等建制），并/分事件 34 条、跨院系/校际师资与系科流向 50 条；
- **时间轴**：网格行覆盖 1896—2026（末行＝当年），块的结束年以「至今」显示；
- **人物词条链接** 101/128 人（口径与待补名单见 `PEOPLE-LINKS.md`）；
- **社群线索** 逐条查证台账见 `SOURCES-COMMUNITY.md`；
- 改动后用 `node tools/check.js` 回归校验（23 项断言），`node tools/check.js --depth` 查看质量达标进度，再 `node tools/build-dist.js 1.1` 重建导出版。
