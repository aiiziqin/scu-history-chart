# 四川大学院系历史沿革全景图（1896—2026）

以 Excel 网格风格展示四川大学各学院、实体研究院所的百年源流：每列一个学院（按学部分组、竖排院名），每行一个年份，单元格颜色代表该学院当年所属的母体大学。

## 看图说明

- **列** = 学院（表头竖排院名，按理学/工学/医学/人文社科/实体研究院所分组）
- **行** = 年份（左侧逐年标注）
- **颜色** = 当年所属母体大学：
  - 🔵 蓝 — 四川大学
  - 🟣 紫 — 四川联合大学（1994—1998，原川大各系所统一显示）
  - 🟠 橙 — 成都工学院 / 成都科学技术大学
  - 🌸 粉 — 华西协合大学 / 四川医学院 / 华西医科大学
  - 🟢 绿 — 四川化学工业学院（1952—1955）
  - ⬜ 灰褐 — 其他来源（燕京大学、教会医院等）
- **半透明色块** = 筹建/中断期；**表头区浅色** = 早于 1896 年基线的源头期（如尊经书院 1875）
- **并 / 分 圆点**（色块分界处）= 红“并”为并入/合组，绿“分”为分出/调出，悬停看详情
- **右栏流向圆标**（入 / 出 / 内 / 组）= 跨院系·校际师资与系科流向：入=调入川大体系，出=调出至他校或新建院校，内=校内院系之间的调整（含校内分设），组=由多校/多系合组；悬停看该年该类逐条流向，点击进入《流向清单》页面（可用图上方复选框开关该图层）
- 悬停任意色块可查看当时名称与起止年份
- 页面**最底部**有「问题反馈 · 意见建议」表单：写好内容点「提交到 GitHub Issues」＝把内容预填进本仓库的新建 Issue 页（确认后点 Submit new issue 即归档，公开可检索、可追加评论）；也可「复制内容」贴到 QQ 群/邮件，「清空」会连本机草稿一起删除；草稿自动存在浏览器本地，刷新或关页不丢（存储位置的取舍见下节《反馈数据存在哪里》）
- 页面**右上角顶栏**：显示本站/本页**浏览量**（不蒜子统计，离线或被拦截时自动隐藏）与**项目地址**（GitHub 仓库）

## 反馈数据存在哪里

静态页面（GitHub Pages）没有后端与数据库，网页自己存不下表单数据，所以反馈统一落到**外部归档处**。本项目的取舍：

| 渠道 | 数据存在哪里 | 需要服务器/密钥吗 | 说明 |
| --- | --- | --- | --- |
| **GitHub Issues（本项目采用）** | 本仓库 Issues 列表 | 否 | 主页表单把填写内容预填进 `/issues/new?title=…&body=…`，确认后发帖即归档：公开、可检索、可加标签与评论，反馈与代码同仓库；新建 Issue 需 GitHub 账号（GitHub 不支持匿名建 Issue） |
| 邮件（`index.html` 里的 `FB_MAIL`） | 维护者邮箱 | 否 | 在 `index.html` 脚本顶部把 `FB_MAIL` 填成邮箱，「改用邮件发送」按钮才会出现（留空则自动隐藏）；适合没有 GitHub 账号或内容不便公开的情况 |
| 复制内容 | 用户自己粘贴到任意渠道（QQ 群 / 邮件） | 否 | 兜底路径：反馈文本不经过任何第三方服务 |
| 浏览器 localStorage | 用户本机（仅草稿） | 否 | 键名 `scu-history-chart/feedback-draft`，只为「刷新/关页不丢草稿」，**不作为正式存档**；隐私模式或被禁用时自动跳过 |
| 第三方表单服务（Formspree / Google Forms / 金数据等） | 服务商后台 | 需要表单端点与账号（多有免费额度） | 想支持「匿名提交」时可用；但要么引外链、要么依赖服务商，与本站「单文件离线可用、无本地依赖」的口径冲突，故未采用 |
| 自建 Serverless（Cloudflare Workers / Vercel）+ 数据库 | 自己的数据库 | 需部署与维护 | 需要去重、统计、后台管理时才值得 |

实现口径：表单**不向本站发送任何请求**，只在点击时用 `encodeURIComponent` 拼出 Issue 链接（正文含反馈类型、涉及位置、内容、联系方式，以及自动附带的来源页面、提交时间与浏览器 UA），并暴露纯函数 `window.FEEDBACK.compose()` 供 `tools/check.js` 断言。

## 文件

- `index.html` — 全景图主页（点击学院名/色块可进入学院页；右栏为流向图层；**底部为「问题反馈 · 意见建议」表单**）
- `college.html` — 学院子页面（条状历史大图，点击时期条目进入详情页）
- `period.html` — 时期详情页（该时期的大事记、成就、代表人物）
- `flows.html` — 跨院系·校际师资与系科流向清单（按年份分组，可按 入/出/内/组 筛选与关键词搜索，支持 `?y=1952&k=出` 定位）
- `SOURCES-COMMUNITY.md` — 社群线索与查证台账（QQ 群具名线索 → 官方来源逐条对照，说明图中“据社群反馈”类表述的依据）
- `PEOPLE-LINKS.md` — 人物词条链接口径（官方页优先 → 百科兜底 → 暂不挂；含官方页对照表与待补名单）
- `tools/build-dist.js` — 导出脚本：`node tools/build-dist.js 1.0` 把 `data.js` 内联进页面，生成 `dist/`
- `tools/check.js` — 回归校验脚本：`node tools/check.js`（加 `--urls` 追加来源 URL 在线存活检查）
- `dist/` — 导出版（构建产物）：四个自包含页面 + `单文件版-四川大学院系沿革图-v2.2.html`（提交入库便于直接分发）
- `data.js` — 共享数据层（院系沿革 `ROWS` + 并/分事件 `EVMARKS` + 师资与系科流向 `FLOWS` + 时期详情 `DETAILS`，可在 `DETAILS` 中继续补充各时期资料）

## 数据说明

院系沿革与研究所信息整理自四川大学校史网及各学院官网公开资料，悬停提示中附关键年代与人物（如芶清泉 1984 年创建原子与分子物理研究所、卿希泰 1980 年创建宗教学研究所等）。如发现出入欢迎提 Issue。

- **时期详情覆盖**：221/221 个时期（100%），每条均含大事记与 GB/T 7714 格式出处；
- **列数** 45（含匹兹堡→奥克兰学院、灾后重建与管理学院等建制），并/分事件 34 条、跨院系/校际师资与系科流向 50 条；
- **时间轴**：网格行覆盖 1896—2026（末行＝当年），所有“延续至今”的块统一延伸到末行，结束年显示为「至今」；
- **人物词条链接** 101/128 人（口径与待补名单见 `PEOPLE-LINKS.md`）；
- **社群线索** 逐条查证台账见 `SOURCES-COMMUNITY.md`；
- 改动后用 `node tools/check.js` 回归校验（30 项断言），`node tools/check.js --depth` 查看质量达标进度，再 `node tools/build-dist.js 2.2` 重建导出版。
